# 提示词写法（Seedance / Seedream）

## 一、视频提示词公式

```
主体 + 动作 + 镜头运动 + 环境/光线 + 风格/质感 + 节奏或情绪
```

- **主体**：谁/什么，尽量带外观锚点（服装颜色、发型、体型），别指望模型记得上一镜。
- **动作**：一个镜头只写 1 个主要动作，动词优先。「奔跑」「回头」「推门」，不要十个动作。
- **镜头**：`固定机位` / `缓慢推进` / `后拉` / `横移跟拍` / `手持跟随` / `环绕` / `低角度仰拍`。
- **环境光线**：时间、天气、光源方向（黄昏逆光、冷色月光、室内暖灯）。
- **风格质感**：`国风2D漫剧` / `赛博霓虹` / `写实电影感` / `水墨`。
- **节奏情绪**：`慢动作` / `快切` / `压抑` / `轻快`。

反例：把「角色设定、剧情、台词、字幕要求、多个镜头」全塞进一条 5 秒视频提示词——模型只会
做出四不像。剧情靠分镜拆，一条视频只表达一个镜头。

## 二、镜头语言速查

| 需求 | 写法 |
|---|---|
| 人物出场 | `中景，人物正面，缓慢推近至近景` |
| 情绪特写 | `面部特写，眼神缓慢抬起，背景虚化` |
| 追逐/奔跑 | `侧向跟拍，镜头随人物横向移动，速度感，扬尘` |
| 环境交代 | `大远景，缓慢横移，雾气弥漫，冷色调` |
| 转场衔接 | `首帧 A 图，尾帧 B 图，镜头从右向左划过` |
| 打斗 | `快速横移 + 短促推拉，动作干脆，1 个交锋即可` |

## 三、首帧工作流（推荐）

人物一致性靠「图」而不是靠「词」。标准链路：

1. 用 Seedream 生成角色定妆/首帧图（`--refs` 同一张角色参考图）。
2. 逐镜检查首帧：构图、服装、表情是否符合该镜头。
3. 用首帧图图生视频：`--image first.jpg`，提示词只描述**运动与镜头**，不再重复外貌。
4. 需要动作首尾呼应时，再补尾帧图 `--last last.jpg`。

首帧图提示词公式：

```
画风 + 人物（外观锚点）+ 动作瞬间 + 景别 + 光线 + 背景 + 画幅
例：国风2D漫剧，少年姜焕，黑色短发、灰布衣、左眉有疤，荒原上回头，中近景，
    黄昏逆光，风沙背景，竖屏
```

## 四、锁角色

- 同一角色所有图都带同一张 `--refs 角色参考.jpg`，并重复关键外观词。
- 视频里用首帧图 + 简短运动提示词，避免「重新描述长相」导致脸漂移。
- 多角色同框：`--refs 角色A.jpg 角色B.jpg`，提示词里明确「左侧 A，右侧 B」。
- 仍然漂移时：固定 `--seed`、换更清晰的正脸参考图、减少画面内人数。

## 五、Seedream 出图要点

- 画幅显式写死：竖屏 `--size 1080x1920`；别只写 `2K`。
- 一张图一个主体动作；多人同框容易糊脸。
- 参考图 2-3 张足够（角色 + 场景 + 风格），过多会互相干扰。
- 文字/字幕不要交给出图模型，后期加。

## 六、负面提示

接口没有独立 negative prompt 字段；把要避免的东西写进正向描述的反面约束，例如：
`画面干净，无文字，无字幕，无多余人物，无变形手指`。仍然失败就换 seed 或简化场景。

## 七、三条可直接用的示例

**1) 国风漫剧·人物出场（首帧生视频）**

```
镜头：缓慢推近
提示词：荒原黄昏，少年回头望向镜头，衣摆被风吹动，尘土轻扬，国风2D动漫质感，
        电影感构图，光线逆光，动作克制
参数：--image first.jpg --ratio 9:16 --resolution 720p --duration 5
```

**2) 城市夜景·情绪空镜（文生视频）**

```
提示词：雨夜霓虹街道，镜头缓慢横移，地面积水倒映灯光，行人虚影掠过，
        赛博朋克色调，电影感，轻微手持晃动
参数：--ratio 16:9 --resolution 720p --duration 4
```

**3) 动作衔接（首尾帧）**

```
提示词：人物从跪地到起身挥剑，镜头轻微后拉，动作连贯，衣料与发丝有惯性
参数：--image start.jpg --last end.jpg --duration 6 --seed 42
```

## 八、验收

- 时长是否接近设定（`ffprobe` 查 `format=duration`）。
- 首帧是否与你给的图一致、人物是否漂移、有没有多手指/多肢体。
- 动作是否完成（很多失败是动作没做完就结束）→ 加时长或简化动作。
- 有无平台水印（脚本已 `watermark:false`，仍出现则检查账户设置）。
